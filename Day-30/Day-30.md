## 📘 Day 30 – Network Performance Monitoring & Optimization

### 🧩 1. What is Network Performance Monitoring?

**Network Performance Monitoring** involves **tracking, analyzing, and optimizing network performance** to ensure reliability and efficiency.

- Helps identify bottlenecks, latency, and packet loss  
- Improves user experience and resource utilization  
- Uses monitoring tools and performance metrics  

Example:
- Monitoring bandwidth usage to prevent congestion  
- Analyzing packet loss to troubleshoot network issues  

---

### 🔢 2. Key Performance Metrics

| Metric | Description |
|--------|-------------|
| Bandwidth | Maximum data transfer capacity of a link |
| Throughput | Actual data transfer rate achieved |
| Latency | Time taken for a packet to travel from source to destination |
| Packet Loss | Percentage of packets lost during transmission |
| Jitter | Variation in packet arrival time, affects real-time traffic |

---

### 🔁 3. Common Monitoring Tools

| Tool | Purpose |
|------|---------|
| Wireshark | Packet capture and analysis |
| PRTG Network Monitor | Bandwidth and device monitoring |
| Nagios | Network and service monitoring with alerts |
| SolarWinds NPM | Network performance management and visualization |
| NetFlow / sFlow | Traffic analysis and flow monitoring |

---

### ⚙️ 4. Optimization Techniques

- Prioritize critical traffic using QoS (Quality of Service)  
- Upgrade network hardware or bandwidth for bottlenecks  
- Segment network using VLANs to reduce broadcast traffic  
- Minimize latency using proper routing and topology adjustments  
- Regularly analyze traffic patterns for performance tuning  

---

### 🗂️ 5. Practical / Lab Practice

- Monitor bandwidth usage with PRTG or SolarWinds  
- Capture and analyze packets using Wireshark  
- Test latency and packet loss using `ping` and `traceroute`  
- Configure QoS on a router or switch for priority traffic  
- Document network performance metrics and improvements  

---

### 🧠 6. Key Terms

- **Bandwidth:** Maximum capacity of a network link  
- **Throughput:** Actual rate of data transfer  
- **Latency:** Delay in packet delivery  
- **Packet Loss:** Lost packets during transmission  
- **QoS:** Quality of Service, prioritizing network traffic
