## 📘 Day 28 – Introduction to Network Security Protocols

### 🧩 1. What are Network Security Protocols?

**Network Security Protocols** are rules and standards designed to **protect data and communication over networks**.

- Ensure confidentiality, integrity, and authentication  
- Protect against unauthorized access and attacks  
- Operate at different layers depending on the protocol  

Example:
- HTTPS secures web traffic  
- SSH provides secure remote access  

---

### 🔢 2. Common Network Security Protocols

| Protocol | Layer | Purpose |
|----------|-------|--------|
| SSL/TLS | Application | Encrypts web communication (HTTPS) |
| SSH | Application | Secure remote login and file transfer |
| IPSec | Network | Secures IP packets over the network |
| SFTP | Application | Secure file transfer over SSH |
| SNMPv3 | Application | Secure network management and monitoring |
| HTTPS | Application | Secure web browsing |
| Kerberos | Application | Authentication protocol for secure login |

---

### 🔁 3. How Security Protocols Work

- **Encryption:** Converts data to unreadable format for unauthorized users  
- **Authentication:** Verifies identity of users or devices  
- **Integrity:** Ensures data is not altered during transmission  
- **Key Exchange:** Securely shares cryptographic keys between parties  

---

### ⚙️ 4. Practical / Lab Practice

- Access a website using HTTPS and check the SSL certificate  
- Connect to a remote server using SSH  
- Transfer files securely using SFTP  
- Configure SNMPv3 on a network device and monitor data  
- Observe encrypted traffic using Wireshark (do not capture sensitive info)  

---

### 🗂️ 5. Key Terms

- **Encryption:** Protects data from unauthorized access  
- **Authentication:** Confirms identity of users or devices  
- **Integrity:** Ensures data is not tampered with  
- **Certificate:** Digital proof of identity for secure communication  
- **VPN/IPSec:** Secure network tunnels for data transmission
