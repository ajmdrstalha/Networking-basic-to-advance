## 📘 Day 15 – Network Monitoring & Tools

### 🧩 1. What is Network Monitoring?

**Network Monitoring** is the process of **continuously observing network performance, traffic, and availability**.

- Ensures uptime and reliability  
- Detects issues before they become critical  
- Uses software and hardware tools  

Example:
- Monitoring bandwidth usage  
- Detecting network downtime  
- Tracking connected devices  

---

### 🔢 2. Types of Network Monitoring

| Type | Description |
|------|-------------|
| Passive Monitoring | Observes network traffic without affecting it |
| Active Monitoring | Sends test packets to check availability and performance |
| Real-time Monitoring | Continuous, live tracking of network metrics |
| Historical Monitoring | Collects and analyzes past network data |

---

### 🔁 3. Common Network Monitoring Metrics

- **Bandwidth Usage:** Amount of data transmitted over time  
- **Latency:** Delay in network communication  
- **Packet Loss:** Percentage of lost packets during transmission  
- **Throughput:** Actual data rate achieved  
- **Uptime/Downtime:** Availability of devices or services  

---

### ⚙️ 4. Popular Network Monitoring Tools

| Tool | Type | Function |
|------|------|---------|
| Wireshark | Packet analyzer | Captures and inspects network packets |
| PRTG | Monitoring software | Monitors bandwidth, devices, and applications |
| Nagios | Monitoring software | Alerts for failures and performance issues |
| SolarWinds | Network management | Performance monitoring and visualization |
| Netstat | Command-line tool | Shows active connections and listening ports |

---

### 🗂️ 5. Practical / Lab Practice

- Capture packets using Wireshark and analyze traffic  
- Check active connections using `netstat -an`  
- Monitor device uptime using PRTG or Nagios  
- Test network speed and latency using online tools  
- Observe bandwidth usage on routers and switches  

---

### 🧠 6. Key Terms

- **Packet Capture:** Recording network packets for analysis  
- **Throughput:** Actual data rate achieved in the network  
- **Latency:** Time taken for data to travel from source to destination  
- **Bandwidth:** Maximum capacity of a network link  
- **Uptime:** Period when a device/service is operational
