## 📘 Day 20 – Network Troubleshooting Commands

### 🧩 1. What is Network Troubleshooting?

**Network Troubleshooting** involves using commands and tools to **identify, diagnose, and resolve network issues**.

- Ensures network connectivity and performance  
- Helps detect misconfigurations, latency, and failures  
- Works for both LAN and WAN environments  

---

### 🔢 2. Common Troubleshooting Commands

| Command | OS | Purpose |
|---------|----|---------|
| ping | Windows/Linux | Tests connectivity to a device or server |
| tracert / traceroute | Windows/Linux | Shows path packets take to a destination |
| ipconfig / ifconfig | Windows/Linux | Displays IP configuration of devices |
| nslookup / dig | Windows/Linux | Tests DNS resolution |
| netstat | Windows/Linux | Shows active connections and listening ports |
| arp | Windows/Linux | Displays ARP table for IP-to-MAC mapping |

---

### 🔁 3. Command Details

- **ping:** Measures reachability and latency  
- **traceroute/tracert:** Identifies each hop along the path  
- **ipconfig/ifconfig:** Check IP, subnet mask, default gateway  
- **nslookup/dig:** Verify domain name resolution  
- **netstat:** Identify open ports and established connections  
- **arp:** Check MAC addresses associated with IPs  

---

### ⚙️ 4. Practical / Lab Practice

- Ping local devices and external servers  
- Use `tracert` or `traceroute` to analyze network path  
- Check your IP configuration and gateway  
- Test DNS resolution using `nslookup` or `dig`  
- Observe active connections with `netstat -an`  
- Display ARP table with `arp -a`  

---

### 🗂️ 5. Key Terms

- **Ping:** Checks connectivity and response time  
- **Traceroute:** Displays hops and delays along network path  
- **IP Configuration:** IP address, subnet mask, gateway info  
- **DNS Resolution:** Mapping domain to IP  
- **ARP Table:** Stores IP-to-MAC mappings
