## 📘 Day 16 – Network Security Basics

### 🧩 1. What is Network Security?

**Network Security** is the practice of **protecting a network and its data from unauthorized access, misuse, or attacks**.

- Ensures confidentiality, integrity, and availability  
- Protects against hackers, malware, and insider threats  
- Uses hardware, software, and policies  

Example:
- Using firewalls and antivirus  
- Securing Wi-Fi with strong passwords  
- Implementing VPNs for remote access  

---

### 🔢 2. Common Network Threats

| Threat | Description |
|--------|-------------|
| Malware | Software that damages or disrupts systems |
| Phishing | Deceptive attempts to steal credentials |
| DDoS | Overloading network resources with traffic |
| Man-in-the-Middle | Intercepting communication between devices |
| Unauthorized Access | Intruders accessing the network without permission |

---

### 🔁 3. Network Security Measures

- **Firewalls:** Control incoming and outgoing traffic  
- **Antivirus / Anti-malware:** Detect and remove malicious software  
- **VPN:** Secure remote connections  
- **Strong Passwords & Authentication:** Prevent unauthorized access  
- **Encryption:** Protects data in transit and at rest  

---

### ⚙️ 4. Security Protocols

| Protocol | Purpose |
|----------|---------|
| SSL/TLS | Encrypts web traffic (HTTPS) |
| IPSec | Secures IP communication |
| SSH | Secure remote command-line access |
| WPA2/WPA3 | Wireless network encryption |
| SNMPv3 | Secure network management |

---

### 🗂️ 5. Practical / Lab Practice

- Configure firewall rules to allow/block traffic  
- Enable WPA2/WPA3 on wireless routers  
- Test VPN connection for secure remote access  
- Scan network for vulnerabilities using tools like Nmap  
- Monitor suspicious activities and logs  

---

### 🧠 6. Key Terms

- **Firewall:** Filters network traffic based on rules  
- **Encryption:** Converts data to secure format  
- **VPN:** Provides secure tunnel over the Internet  
- **Authentication:** Verifies user/device identity  
- **Intrusion Detection System (IDS):** Detects malicious activities
