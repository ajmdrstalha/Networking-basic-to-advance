## 📘 Day 12 – VPN Basics

### 🧩 1. What is a VPN?

A **VPN (Virtual Private Network)** is a technology that **creates a secure and encrypted connection over a public network**, like the Internet.

- Protects data from eavesdropping  
- Provides secure remote access  
- Masks the user’s IP address  

Example:
- Employee accessing office network from home  
- Securing data on public Wi-Fi  

---

### 🔢 2. Types of VPN

| Type | Description |
|------|-------------|
| Remote Access VPN | Individual users connect securely to a private network |
| Site-to-Site VPN | Connects entire networks at different locations |
| Client-based VPN | Requires VPN client software on the device |
| SSL VPN | Browser-based secure VPN using SSL/TLS |

---

### 🔁 3. How VPN Works

1. User initiates a VPN connection  
2. VPN client encrypts data before sending  
3. Data travels through public Internet securely  
4. VPN server decrypts data at the destination  

---

### ⚙️ 4. VPN Protocols

| Protocol | Function |
|----------|---------|
| PPTP | Older, fast but less secure |
| L2TP/IPSec | Combines L2TP tunneling with IPSec encryption |
| OpenVPN | Open-source, highly secure, supports TCP/UDP |
| IKEv2/IPSec | Secure, fast reconnection for mobile users |

---

### 🗂️ 5. Practical / Lab Practice

- Test VPN connection on your device  
- Observe IP change using `whatismyip.com`  
- Test access to private network resources via VPN  
- Compare speed and latency before and after VPN  

---

### 🧠 6. Key Terms

- **VPN Tunnel:** Encrypted path between client and server  
- **Encryption:** Securing data so only intended recipient can read it  
- **Authentication:** Verifying identity of VPN user/device  
- **Client:** Device connecting to VPN  
- **Server:** Device/network accepting VPN connections
