## 📘 Day 27 – Introduction to Network Protocols

### 🧩 1. What is a Network Protocol?

A **Network Protocol** is a set of **rules and standards** that defines how devices communicate over a network.

- Ensures interoperability between devices  
- Governs data format, transmission, error handling, and routing  
- Operates at different layers of the OSI and TCP/IP models  

Example:
- TCP ensures reliable delivery of data  
- HTTP allows web browsers to communicate with web servers  

---

### 🔢 2. Common Network Protocols

| Protocol | Layer | Purpose |
|----------|-------|--------|
| TCP | Transport | Reliable connection-oriented communication |
| UDP | Transport | Connectionless, faster communication |
| IP | Network | Routing packets across networks |
| ICMP | Network | Sends control and error messages (ping) |
| HTTP/HTTPS | Application | Web communication |
| FTP | Application | File transfer |
| DNS | Application | Resolves domain names to IP addresses |
| DHCP | Application/Network | Assigns IP addresses dynamically |

---

### 🔁 3. Protocol Types

- **Connection-oriented (TCP):** Ensures data delivery in order  
- **Connectionless (UDP):** Sends data without ensuring delivery  
- **Routing Protocols:** OSPF, EIGRP, BGP, RIP – determine best path for packets  
- **Application Protocols:** HTTP, FTP, DNS, SMTP – enable specific services  

---

### ⚙️ 4. Practical / Lab Practice

- Test connectivity using `ping` (ICMP)  
- Transfer files using FTP or SFTP  
- Access websites using HTTP and HTTPS  
- Observe packet flow using Wireshark  
- Identify protocol usage for different services  

---

### 🗂️ 5. Key Terms

- **TCP:** Transmission Control Protocol, reliable delivery  
- **UDP:** User Datagram Protocol, fast but unreliable  
- **ICMP:** Internet Control Message Protocol for diagnostics  
- **Routing Protocol:** Determines paths for packets  
- **Application Protocol:** Defines rules for specific applications
