## 📘 Day 21 – Introduction to Cloud Networking

### 🧩 1. What is Cloud Networking?

**Cloud Networking** involves using **networking services and infrastructure delivered via cloud providers**.

- Enables access to resources without physical hardware  
- Provides scalability, flexibility, and high availability  
- Common providers: AWS, Azure, Google Cloud  

Example:
- Hosting web servers in the cloud  
- Connecting multiple cloud resources across regions  

---

### 🔢 2. Key Components of Cloud Networking

| Component | Description |
|-----------|-------------|
| VPC (Virtual Private Cloud) | Isolated network environment in the cloud |
| Subnet | Subdivision of a VPC for organizing resources |
| Internet Gateway | Connects VPC to the Internet |
| NAT Gateway | Allows private instances to access the Internet |
| Security Groups | Virtual firewall controlling traffic to instances |
| Route Table | Defines routing paths inside the VPC |

---

### 🔁 3. Cloud Networking Models

| Model | Description |
|-------|-------------|
| IaaS (Infrastructure as a Service) | Provides virtual networks, compute, and storage |
| PaaS (Platform as a Service) | Manages underlying network and infrastructure for apps |
| SaaS (Software as a Service) | Users access software over the network, provider manages everything |

---

### ⚙️ 4. Practical / Lab Practice

- Create a VPC with public and private subnets in AWS or Azure  
- Configure route tables and attach an Internet Gateway  
- Launch instances in different subnets and test connectivity  
- Apply security group rules to allow/deny traffic  
- Observe how NAT Gateway allows private instances to access the Internet  

---

### 🗂️ 5. Key Terms

- **VPC:** Virtual network in the cloud  
- **Subnet:** Smaller network segment within VPC  
- **Internet Gateway:** Connects cloud network to Internet  
- **NAT Gateway:** Provides Internet access for private instances  
- **Security Group:** Firewall rules for cloud instances
